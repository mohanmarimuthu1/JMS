# Print engine

## The problem this solves

The prototype's printed invoice matched the shop's paper bill book by
accident, not by design: no `@page` rule (so paper size and margins
were whatever Chrome's shrink-to-fit picked), no page-break rules (so a
long invoice sliced its own frame mid-row), and a font that silently
fell back to the browser default because the `<style>` tag carrying it
was unmounted during print. See `docs/DECISIONS.md` for the full
argument for why this was tackled first, before any database code.

## The three fixtures

`src/fixtures/*.json`, generated by `scripts/gen-fixtures.mjs` (not
shipped in the app — it exists only to make the fixtures internally
consistent, e.g. the words in `invoice-max.json` actually match its
stored total):

| Fixture | Purpose |
|---|---|
| `invoice-min` | 1 line, no order number — the smallest real invoice. |
| `invoice-max` | 18 lines with long wrapping descriptions, forces a page break, checks the totals/signature block don't orphan. |
| `dc-max` | Delivery challan — no tax, no amount-in-words, 4-column table. |

Regenerate with `node scripts/gen-fixtures.mjs` if the shapes in
`src/documents/types.ts` change.

## Two ways to check print output

**1. Automated — `node scripts/verify-print.mjs`** (needs the app
running, e.g. `npm run preview`). For each fixture: zero console
errors, zero external network requests (proves fonts/logo are bundled,
not fetched — a request that resolves after `window.print()` fires is
exactly how the prototype's font bug happened), and a sane PDF page
count (`invoice-max` must span more than one A4 page; the others must
fit on one). This is a regression net, not a substitute for looking at
the page.

**2. Manual — the golden-sample test.** Open each
`/print/fixture/:name` route, click Print, and compare the physical
output against a real bill from the shop's paper book (not against
the old prototype's output — it has known defects, listed below).
Full checklist in the approved plan; the short version:

1. One A4 sheet, no shrink-to-fit, no blank trailing page.
2. Border unbroken, box fills the printable width.
3. Correct fonts — verify once with the network disabled.
4. Dates `DD-MM-YYYY`.
5. Words say "Rupees" once, not twice; non-zero paise render as
   "... and N Paise".
6. Words and the printed total figure agree exactly.
7. `invoice-max`: table header repeats on page 2, no row split by a
   page break, totals+signature block doesn't orphan alone on a page.
8. Mobile Chrome print → Save as PDF matches desktop.
9. Same fixture printed twice is byte-for-byte the same.
10. A first-time, non-technical user finds the print button unaided.

## Defects fixed relative to the prototype (deliberately, not silently)

| # | Prototype (`reference/billing-system.jsx`) | This build |
|---|---|---|
| 1 | Raw ISO dates, e.g. `2026-09-14` (`:895`) | `formatDateDDMMYYYY()` in `src/lib/money.ts` |
| 2 | "**Rupees** ... **rupees** only." — duplicated word (`:943`) | Single "Rupees ... Only" (see `scripts/gen-fixtures.mjs`'s `wordsInr`, mirrored in Postgres in Slice 2) |
| 3 | `numToWords` rounds to whole rupees while the printed total shows 2 decimals — the two can disagree (`:36`, `:64`) | `total` is a whole rupee by DB constraint (Slice 2); words are derived from that same stored value, never recomputed |
| 4 | `.mono`/`.headline` and the Google Fonts `@import` live in a `<style>` inside the app shell, which print unmounts (`:146-151`, `:128-132`) | Fonts bundled in `main.tsx`; global styles in `src/index.css`, never unmounted |
| 5 | No `@page` rule; relies on Chrome's shrink-to-fit (`:859-864`) | `@page { size: A4; margin: 10mm }` in `src/index.css` |
| 6 | No page-break rules; fixed 24px row height breaks on wrapped text (`:855-856`, `:928`) | `break-inside: avoid`, repeating `<thead>`, `min-height` rows that can grow |
| 7 | Logo is a data URI (fine) but Slice 6/7 of the original plan proposed moving it to Supabase Storage — an async fetch racing `window.print()` | Kept as a bundled static asset (`src/assets/logo.jpg`); see `docs/DECISIONS.md` "Cuts" |
